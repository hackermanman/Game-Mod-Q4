HOW TO PLAY:

Enter game as usual, your greeted with a pick a kart screen (button press 1, 2, 3 to corresponding vehicle) 

Hold W to move forward.
Turn using the A and D keys.
Hold S to Reverse.

avoid obstacles such as jump pads, spikes, saws, get speed boosts on the track. 

Pick up skulls for items 

Left click to use items picked up. 

Complete 5 laps, finish in first to win.

See a help screen to learn how to play the game by holding TAB
